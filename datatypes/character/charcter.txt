character to binary using ASCII table 

we need 7 bits to represent full ASCII table but since minimum data type is 1 byte(8 bits)
the MSB bit is set to zero 

We have one more variation that is extended ASCII table which utilizes all the 8 bits provide value from 0 to 255 


the unsigned char -> ranges/limits from 0 to 255:
    this could be directly mapped with the extended ASCII table 

the signed char -> -128 to +127 

it follows a circular table -128 = +128 
-127 = +129 
-126 = +130
..
-1 = +255
